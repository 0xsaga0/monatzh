# Монтаж кодом: инструкция для ИИ-агента

Ты помогаешь человеку, который не пишет код, монтировать вертикальные и горизонтальные ролики: распознать речь, вырезать паузы, наложить караоке-субтитры и отрендерить MP4. Стек: **Remotion** (видео из кода), **whisper.cpp** (распознавание речи с временем каждого слова), **ffmpeg** (уже встроен в Remotion). Правила монтажа — в `RULES.md`.

Говори с человеком простыми словами, без жаргона. Если у тебя есть доступ к терминалу (Claude Code, Cursor, Codex и т. п.) — выполняй команды сам и показывай только результат. Если доступа нет (обычный чат) — давай по одной команде, объясняй, куда её вставить, и жди, что человек пришлёт в ответ.

## Что в этой папке

| Файл | Зачем |
|---|---|
| `README.md` | Короткая инструкция для человека |
| `RULES.md` | Правила монтажа — читай перед каждым роликом |
| `PROMPTS.md` | Готовые фразы, которые человек может тебе писать |
| `package.json` | Зависимости и команды `npm run …` |
| `scripts/` | Конвейер: проверка, установка whisper, звук, распознавание, таймлайн, рендер |
| `src/` | Remotion: композиция `Edit`, субтитры (`Captions.tsx`), стиль (`style.ts`), шрифт (`fonts.ts`) |
| `public/` | Сюда кладутся исходники; сюда же скрипты пишут звук, слова и таймлайн |
| `out/` | Готовые кадры и ролики |

## Как ты работаешь

1. `RULES.md` — единственный источник правил. Читай его в начале каждой сессии и перед каждым роликом.
2. Правку от человека классифицируй: разовая или постоянная. Постоянную **не записывай в RULES.md молча** — спроси разрешения.
3. Не угадывай непонятные слова в субтитрах — выпиши их списком и спроси.
4. Решения по виду принимай на одном кадре (`npm run still`), а не на полном рендере. Если человек сомневается — покажи два варианта одного кадра.
5. Не трогай ничего за пределами этой папки и папки whisper. Не удаляй исходники в `public/` без прямой просьбы.
6. Прежде чем сказать «готово», пройди чек-лист из `RULES.md` (правило 10) по готовому файлу.

## Установка (один раз)

После каждого шага проверь, что он сработал, и только потом иди дальше.

### 0. Путь без пробелов и кириллицы

npm, Remotion и особенно установщик whisper.cpp ломаются, если в пути к папке есть пробел или русские буквы. Проверь путь к этой папке. Если он вроде `C:\Users\Иван\Downloads\monatzh-main` (так ложится архив с GitHub) — предложи перенести папку в `C:\montazh` (Windows) или `~/montazh` (macOS/Linux) и открыть её заново.

### 1. Node.js LTS (20 или новее)

Проверка: `node -v`.

- Windows: `winget install OpenJS.NodeJS.LTS`, затем закрыть и заново открыть терминал. Без winget — установщик с https://nodejs.org (кнопка LTS).
- macOS: установщик с https://nodejs.org или `brew install node`.
- Linux: пакет из https://nodejs.org или через nvm.

### 2. Зависимости проекта

`npm install` в этой папке. Ставится около 260 пакетов, несколько минут.

### 3. Скиллы Remotion для агента

`npx skills add remotion-dev/skills`

Это официальные инструкции Remotion для ИИ-агентов: субтитры, звук, превью, рендер — по документации той версии, что стоит в проекте. Без них агент пишет код Remotion по памяти, а память бывает устаревшей. Если команда не сработала или изменилась — найди актуальную в документации Remotion (раздел про AI / skills) и продолжай без них: проект работает и так.

### 4. ffmpeg — ничего не ставить

ffmpeg и ffprobe уже встроены в Remotion. Проверка: `npx remotion ffmpeg -version`. Скрипты проекта вызывают его сами.

### 5. Whisper

`npm run setup:whisper`

Ставит whisper.cpp 1.5.5 и модель `medium` (~1,5 ГБ) в `C:\whisper` (Windows) или `~/whisper` (macOS/Linux). Другую папку задаёт переменная `WHISPER_HOME` — тоже без пробелов.

- Слабый компьютер или мало места — модель `small`: перед командами задать `WHISPER_MODEL=small` (Windows PowerShell: `$env:WHISPER_MODEL="small"`). Качество распознавания ниже.
- macOS: whisper.cpp собирается из исходников, нужны инструменты разработчика: `xcode-select --install`. Linux: `git`, `make`, `g++`.
- Распознавание идёт на процессоре, без интернета и без подписок.
- Если whisper уже стоит в другой папке — задай `WHISPER_HOME` на неё и пропусти шаг.

### 6. Проверка

`npm run doctor` — все строки должны быть с ✓. Если есть ✗ — под ней написано, что сделать.

При первом рендере Remotion сам скачает браузер, которым «фотографирует» кадры (~270 МБ). Это один раз и может занять несколько минут.

## Монтаж одного ролика

Имя ролика `<имя>` — латиницей, без пробелов, например `reel01`. Все команды — из корня проекта.

1. **Исходник** — `public/<имя>.mp4` (подойдут и `.mov`, `.mkv`, `.webm`, `.m4v`).
2. **Звук** — `npm run audio -- <имя>` → `public/<имя>.wav` (моно, 16 кГц — формат для whisper).
3. **Распознавание** — `npm run transcribe -- <имя>` → `public/<имя>.words.json` (слова с временем) и `public/<имя>.txt` (сплошной текст). На процессоре это примерно вдвое дольше записи.
4. **Вычитка** (правило 2) — самый важный шаг:
   - прочитай `public/<имя>.txt` целиком;
   - скопируй `public/<имя>.words.json` в `public/<имя>.words.fixed.json` и исправь поле `text` у ошибочных слов. Пробел в начале `text` сохраняй — он разделяет слова;
   - время (`startMs`, `endMs`) не трогай. Если два куска — одно слово, объедини их: `startMs` первого, `endMs` последнего;
   - удали фразы, которых не было в речи (whisper дописывает их на тишине и в конце: «Продолжение следует», «Субтитры сделал…», «Редактор субтитров…», «С вами был…»);
   - сомнительные места выпиши человеку списком с вопросом и дождись ответа.
5. **Таймлайн** — `npm run timeline -- <имя>` → `public/<имя>.timeline.json`. Скрипт вырезает паузы длиннее 0,4 с с запасом 0,08 с, отрезает хвост после последнего слова и собирает страницы субтитров. Покажи человеку сводку: сколько было, сколько стало.
6. **Проверочный кадр** — `npm run still -- <имя> 60` → `out/<имя>-60.png` (60 — номер кадра: при 30 кадрах в секунду это 2-я секунда). Открой или покажи картинку. Для живого просмотра — `npm run studio`, композиция `Edit`; имя ролика меняется в props справа.
7. **Рендер** — `npm run render -- <имя>` → `out/<имя>.mp4`. При 8 ГБ памяти — `npm run render -- <имя> --concurrency=2`.
8. **Громкость** (правило 6): `npx remotion ffmpeg -i out/<имя>.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5:LRA=11 -c:a aac -b:a 192k out/<ГГГГ-ММ-ДД>_<тема>.mp4`.
9. **Чек-лист** — правило 10 из `RULES.md`, отдельным проходом по готовому файлу.

Несколько роликов подряд — повтори шаги для каждого имени. Если роликов много, предложи написать пакетный скрипт: одна сборка проекта и рендер всех таймлайнов через `@remotion/renderer` — так быстрее, чем `npm run render` для каждого по отдельности.

## Как менять вид

- Цвет, размер, позиция субтитров — `src/style.ts`. Шрифт — `src/fonts.ts` (любой из Google Fonts через `@remotion/google-fonts`, подключай только нужные начертания). Если правка постоянная — синхронно обнови правило 3 в `RULES.md` (с разрешения).
- Музыка (правило 5) — поставь `npx remotion add @remotion/media`, положи трек в `public/music/` и добавь `<Audio>` с `volume={0.08}` в `src/Edit.tsx`.
- Вторая строка субтитров (перевод), логотип, размытие участка кадра, заставка — добавляются в `src/Edit.tsx` отдельным компонентом. Сначала покажи один кадр.
- Перед любыми правками кода Remotion сверяйся со скиллами Remotion, если они установлены.

## Известные грабли

| Что видно | Почему | Что делать |
|---|---|---|
| npm или установка whisper падает с непонятной ошибкой | пробел или кириллица в пути | перенести папку (шаг 0), для whisper — `WHISPER_HOME` без пробелов |
| В конце субтитров фразы, которых никто не говорил | whisper «дописывает» на тишине | удалить при вычитке (шаг 4) |
| Подсветка слов отстаёт или убегает на отдельном куске | whisper.cpp сдвигает время слов на границах 30-секундных окон | поправить `startMs`/`endMs` этих слов по звуку или распознать кусок отдельно |
| Пауза не вырезалась | whisper растянул `endMs` слова на тишину | найти тишину по звуку: `npx remotion ffmpeg -i public/<имя>.wav -af silencedetect=noise=-28dB:d=0.35 -f null -` и укоротить `endMs` |
| Щелчок или съеденный звук на стыке | срез слишком близко к слову | увеличить `PAD_MS` в `scripts/build-timeline.mjs` |
| Компьютер задыхается при рендере | по умолчанию открыто много вкладок браузера (пик ~5,5 ГБ памяти) | `--concurrency=2` |
| Каждый рендер долго «готовится» | Remotion перед рендером копирует всю папку `public/` | убрать из `public/` старые исходники и готовые файлы |
| Шрифт не тот или рендер падает на шрифте | шрифт качается из интернета при рендере | проверить интернет; не подключать лишние начертания |
| В Studio надпись «Нет public/<имя>.timeline.json» | не тот `name` в props или таймлайн не собран | поменять `name` в props или выполнить шаги 2–5 |
