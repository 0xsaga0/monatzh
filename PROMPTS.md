# Что писать ИИ

Копируй и вставляй как есть, меняй только имя ролика.

## Первый запуск

> Прочитай CLAUDE.md и RULES.md. Установи всё по разделу «Установка», после каждого шага проверяй, что сработало. В конце запусти npm run doctor и покажи результат.

## Смонтировать ролик

> Я положил видео в public/reel01.mp4. Смонтируй его по RULES.md: звук, распознавание, вычитка, таймлайн. Перед рендером покажи один кадр и список слов, в которых не уверен.

## Посмотреть, как выглядят субтитры

> Покажи один кадр субтитров с 5-й секунды ролика reel01. Полностью не рендери.

> Покажи этот кадр в двух вариантах: как сейчас и с субтитрами крупнее и ниже. Я выберу.

## Правка

> Сделай субтитры ниже.

ИИ спросит, для этого ролика или навсегда. «Навсегда» — правило запишется в RULES.md.

## Несколько роликов

> В public/ лежат reel01.mp4, reel02.mp4 и reel03.mp4. Смонтируй их по очереди по RULES.md. Вычитку покажи по каждому отдельно.

## Музыка

> Добавь фоном музыку public/music/track.mp3 по правилу 5. Проверь, что голос не перекрывается.

## Что-то сломалось

> Запусти npm run doctor и почини то, что с ✗. Объясни простыми словами, что было не так.
