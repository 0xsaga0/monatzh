# Инструкция для ИИ-агента

Основная инструкция — в `CLAUDE.md` (установка, монтаж ролика, грабли), правила монтажа — в `RULES.md`. Прочитай оба файла целиком, прежде чем что-то делать. Этот файл нужен агентам, которые ищут `AGENTS.md` (Codex, Cursor и другие): всё написанное в `CLAUDE.md` относится и к тебе.
