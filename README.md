# Монтаж кодом: Remotion + Whisper + ffmpeg

Набор, чтобы ИИ монтировал за тебя: распознаёт речь, вырезает паузы, накладывает караоке-субтитры и собирает MP4. Ты пишешь обычными словами, код пишет ИИ.

На этих правилах я смонтировал больше 60 роликов, ни разу не открыв видеоредактор.

— Ярослав Черчик, Telegram: https://t.me/CherchikYaroslaVo

## Что нужно

- Компьютер на Windows, macOS или Linux. Комфортно — 16 ГБ памяти, на 8 ГБ работает медленнее.
- Около 3 ГБ на диске: проект, браузер для рендера и модель распознавания речи.
- Интернет — на установку и для шрифта при рендере. Само распознавание работает без интернета.
- ИИ-агент с доступом к папке: **Claude Code** (расширение VS Code или приложение), Cursor, Codex. Подойдёт и обычный чат — тогда ИИ будет давать команды по одной, а вставлять их в терминал будешь ты.

## Три шага

1. **Распакуй архив** в папку без пробелов и русских букв: `C:\montazh` на Windows, `~/montazh` на Mac. Это важно: с пробелом в пути распознавание речи не установится.
2. **Открой эту папку в ИИ-агенте.** В VS Code: «File → Open Folder» → `montazh`, затем открыть Claude Code. Если у тебя обычный чат — загрузи в него `CLAUDE.md` и `RULES.md`.
3. **Напиши ИИ:**
   > Прочитай CLAUDE.md и RULES.md. Установи всё по разделу «Установка», после каждого шага проверяй, что сработало.

Дальше — положи своё видео в папку `public/` и напиши: «Смонтируй public/reel01.mp4 по RULES.md». Готовые фразы для всех случаев — в `PROMPTS.md`.

## Что внутри

| Файл | Что это |
|---|---|
| `CLAUDE.md` | инструкция для ИИ: установка, монтаж по шагам, известные грабли |
| `AGENTS.md` | то же для Codex, Cursor и других агентов |
| `RULES.md` | мои 10 правил монтажа и чек-лист перед сдачей — меняй под себя |
| `PROMPTS.md` | что писать ИИ |
| `scripts/`, `src/` | готовый проект: проверка окружения, установка whisper, распознавание, нарезка пауз, субтитры, рендер |

## Сколько это ест — замерил на своём ноутбуке

Core i5 11-го поколения, 16 ГБ памяти, видеокарта не используется:

- рендер 32 секунд вертикали — около 70 секунд;
- пик памяти при рендере — около 5,5 ГБ;
- распознавание речи — примерно вдвое дольше самой записи;
- инструменты на диске — меньше 2,5 ГБ.

## Когда это не нужно

Если ты делаешь один ролик в неделю — открой CapCut, будет быстрее. Этот набор окупается, когда роликов много и они должны быть в одном стиле: серия шортсов, нарезки подкаста, обучающие видео. Финальный ролик всё равно смотрит человек.
